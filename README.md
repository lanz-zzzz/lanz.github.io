# 🎯 私募基金客户看板交互原型

一个面向**非技术背景高净值客户**的交互式数据看板，旨在将复杂的私募基金收益、风险与归因数据，转化为清晰、易懂、可执行的洞察。

**👉 [在线体验链接](https://lanz-zzzz.github.io/lanz/)**

---

## 📋 项目背景与目标

**核心问题**：传统基金报告充斥着专业术语（如夏普比率、最大回撤），普通客户难以理解“我赚/亏了多少钱？”以及“**为什么会这样？**”

**项目目标**：设计并实现一个移动端优先的看板，让客户在1分钟内：
1.  **看清结果**：了解核心收益与风险概况。
2.  **看懂原因**：定位业绩波动的核心驱动因素。
3.  **感知安全**：直观评估自身投资的风险状况。

---

## ✨ 设计亮点与解决方案

### 1. 三层信息架构，逻辑闭环
- **首页（概览）**：呈现“本月收益”、“累计收益”、“跑赢大盘”三个最核心指标，搭配收益趋势与资产分布图，**第一眼定调**。
- **波动原因（归因）**：通过“本月赚钱方向”与“调整原因”正负列表，用通俗语言（如“重仓科技股上涨”）**直接回答“为什么”**。
- **风险体检（分析）**：将专业指标转化为“投资健康度（82分）”、“收益稳定性（⭐⭐⭐）”等可视化评分，**降低认知门槛**。

### 2. 主动式洞察，而非被动呈现
- **智能诊断卡片**：在首页主动对本月表现进行一句话解读（如“主要受益于科技股上涨”），并支持**一键下钻**查看详情，变“用户寻找”为“产品告知”。

### 3. 客户语言，告别黑话
- 将“超额收益”显示为“**跑赢大盘：+3.2%**”。
- 将“历史最大回撤”解释为“**历史最大亏损**”，并与同类平均对比。
- 用“**压力测试**”模块说明极端市场下的可能表现，提供“客户建议”，体现专业陪伴感。

---

## 🛠 技术实现

- **前端**：原生 HTML、CSS、JavaScript
- **数据可视化**：ECharts
- **部署**：GitHub Pages
- **交互**：纯前端实现，无需后端支持

---

## 🚀 项目流程

本项目完整遵循了从概念到上线的产品开发流程：
1.  **需求分析**：定位非技术客户的认知痛点。
2.  **产品架构**：设计“总-分”式信息结构与用户交互流程。
3.  **原型与设计**：完成高保真可交互原型。
4.  **开发实现**：使用前端技术进行编码实现。
5.  **部署上线**：通过 GitHub Pages 发布为可公开访问的网页。

---

## 📁 项目结构

本原型采用**单一HTML文件**结构，便于快速部署与演示。所有样式、逻辑与可视化代码均内联。
---

## 💡 后续思考

该项目作为MVP（最小可行产品），未来可深化方向包括：
- **动态数据**：接入模拟API，实现图表数据的动态更新。
- **个性化配置**：允许用户切换查看不同时间周期或对比基准。
- **深度归因**：加入行业、风格因子等更专业的归因分析层（可设置为“专家模式”）。
