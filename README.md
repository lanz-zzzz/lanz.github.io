# 🎯 私募基金客户看板交互原型

一个面向**非技术背景高净值客户**的交互式数据看板，旨在将复杂的私募基金收益、风险与归因数据，转化为清晰、易懂、可执行的洞察。

**👉 [在线体验链接](https://lanz-zzzz.github.io/lanz.github.io/)**

---

## 📋 项目背景与目标

**核心问题**：传统基金报告充斥着专业术语（如夏普比率、最大回撤），普通客户难以理解“我赚/亏了多少钱？”以及“**为什么会这样？**”

**项目目标**：设计并实现一个移动端优先的看板，让客户在1分钟内：
1. **看清结果**：了解核心收益与风险概况。
2. **看懂原因**：定位业绩波动的核心驱动因素。
3. **感知安全**：直观评估自身投资的风险状况。

---

## ✨ 设计亮点与解决方案

### 1. 三层信息架构，逻辑闭环

- **首页（概览）**：呈现“本月收益”、“累计收益”、“跑赢大盘”三个最核心指标，搭配收益趋势图与资产分布饼图，**第一眼定调**。
- **操作复盘（归因）**：通过“操作亮点”与“反思优化”双栏对比，用通俗语言**直接回答“为什么要调仓”**。
- **风险体检（分析）**：将专业指标转化为“投资健康度（82分）”、“收益稳定性（⭐⭐⭐⭐）”等可视化评分，**降低认知门槛**。

### 2. 主动式洞察，而非被动呈现

- **智能诊断卡片**：在首页主动对本月表现进行一句话解读，并支持**一键展开**查看详情，变“用户寻找”为“产品告知”。
- **调仓瀑布图**：使用瀑布图直观展示每次调仓对累计超额收益的贡献，让客户一眼看懂“哪次操作赚了、哪次亏了”。

### 3. 客户语言，告别黑话

- 将“超额收益”显示为“**跑赢大盘：+3.2%**”，并附计算公式。
- 将“历史最大回撤”解释为“**历史最大亏损**”，并与同类平均对比。
- 用“**陪伴寄语**”模块提供市场解读与投资建议，体现专业陪伴感。

### 4. 调仓归因，透明可见

- 在收益趋势图上使用**可点击的调仓标记**（三角形图标），点击即可查看该次调仓的详细信息，并可跳转至对应的操作复盘报告。
- 调仓明细表支持**日期点击跳转**，直达对应的操作复盘详情页，实现“发现波动 → 查看原因”的完整闭环。

### 5. 基金经理信息，建立信任

- 在“联系顾问”浮窗中展示基金经理的**从业年限、管理规模、投资风格**等信息，增强客户对管理团队的信任感。
